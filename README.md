# 개발자 포트폴리오 RAG 챗봇

Next.js 기반 프로젝트입니다. 기획/설계 문서는 아래를 참고하세요.

- [CLAUDE.md](./CLAUDE.md) — 작업 규칙, 기술 스택, 제품 규칙 요약
- [PRD.md](./PRD.md) — 정식 기획서
- [PLAN.md](./PLAN.md) — 개발 작업 목록
- [DESIGN.md](./DESIGN.md) — 화면 구성, 데이터 흐름, 기술 선택, DB/API 설계

## 개발 서버 실행

```bash
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000) 을 열어 확인합니다.
